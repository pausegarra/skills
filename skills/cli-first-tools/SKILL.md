# CLI-First Tools

When a user asks to find, read, create, update, or otherwise operate on a service, platform, or application, use its relevant CLI first whenever one is available and supports the requested operation. This applies to any platform, including GitHub, Azure, Jira, and others.

Check and use the CLI before browser UI, connectors or MCP tools, or direct APIs.

If no suitable CLI is available or it cannot perform the operation, use the next suitable tool.
